## 11.2 L-01: 賭博罪リスク（最重要）

### 法的構造
- 刑法185条: 「賭博をした者は、五十万円以下の罰金又は科料に処する」
- 賭博の構成要件: **「財物・財産上の利益」を「賭ける」**
- 例外: 「一時の娯楽に供する物を賭けたとき」は不罰（コーヒー1杯程度）

### 本プロジェクトの該当性検討

#### Phase 1〜2（チップのみ）
- ゲーム内チップに**換金性がない** → 「財物・財産上の利益」性なし
- ✅ 賭博罪該当の可能性は**極めて低い**
- ただし、運営として以下を明示する必要:
  - チップは現金・暗号資産と交換できないこと
  - チップに金銭的価値はないこと
  - 利用規約に明記、UIにも表示

#### Phase 3（トークン導入後）
- $FGT が**暗号資産**または**財産上の利益**と判定されると賭博罪リスクが急上昇
- 暗号資産該当性 → L-02で詳述
- リスク回避には:
  - $FGT自体の換金性を排除する設計
  - 「賭ける」要素ではなく「参加費・利用料」として位置づける
  - 勝敗の結果による$FGTの増減ではなく、固定のシーズン報酬として配布

### 対策
1. **チップ・トークン共に換金性を持たせない** （技術的・契約的の両面）
2. **利用規約に明記**: 「賭博目的での使用禁止、金銭的価値なし」
3. **UIで明示**: チップ画面に「※ゲーム内通貨、金銭価値なし」を常時表示
4. **Phase3前に弁護士確認**: トークンの構造について必ず事前相談
5. **広告表現の制限**: 「儲かる」「稼げる」表現を禁止（社内ガイドライン）

## 11.3 L-02: 暗号資産業リスク（Phase 3）

### 法的構造
- 資金決済法2条5項: 暗号資産の定義
- 該当要件:
  - ①不特定の者に対する支払いに使用できる
  - ②不特定の者を相手に売買等ができる
- 暗号資産該当 → 暗号資産交換業の登録義務

### 本プロジェクトの該当性検討

#### $FGTの設計次第
- **ユーティリティトークンとして設計**: ゲーム内利用に限定すれば①②該当しにくい
- **ただし**、DEXで自然発生的に取引される可能性 → 「不特定の者を相手に売買等」に該当の余地
- 完全な回避は困難、運営として**売買を推奨・誘導しない**ことが重要

### 対策
1. ゲーム内ユーティリティ限定設計（技術的に変換手段を提供しない）
2. 利用規約で「投機目的の取得・売買を推奨しない」と明記
3. 流動性プール提供を運営として行わない
4. 弁護士・場合によっては金融庁への事前照会
5. 「金融庁ガイドラインに準拠」を継続的に確認

## 11.4 L-03: 前払式支払手段リスク

### 法的構造
- 資金決済法3条: 前払式支払手段の定義
- 発行残高が一定額（1000万円）を超えると届出義務

### 本プロジェクトの該当性
- ゲーム内チップが**現金で購入できる**仕様だと該当の可能性
- → **チップを現金で売らない**設計で回避

### 対策
- チップは無料配布（初期付与、デイリーボーナス、プレイ報酬）のみ
- 課金（チップ購入）を**実装しない**（少なくともPhase 3初期は）

## 11.5 L-04: 金融商品取引法リスク

### 法的構造
- 金商法2条3項: 集団投資スキーム持分の定義
- 該当要件:
  - 投資者から金銭を集める
  - 事業から生じる収益を分配する
  - → 該当すると有価証券届出書提出義務、ファンド業登録等

### 本プロジェクトの該当性
- $FGTの保有者に「事業収益を分配」する仕組みを作ると該当の可能性
- ステーキング報酬等で「利回り」を訴求すると危険

### 対策
- 「投資」「利回り」「リターン」等の表現を一切使わない
- $FGT保有者への分配は「ゲーム内特典」のみとし、金銭的価値訴求しない
- ホワイトペーパー等の表現を弁護士チェック

## 11.6 L-05: NFT・IP利用リスク

### 法的構造
- NEOTOKYOPUNKSのNFTおよび関連IP（キャラクター、ロゴ、世界観）は権利者保有
- 著作権・商標権・パブリシティ権の問題

### 本プロジェクトでの利用範囲
| 利用 | リスク | 対応 |
|---|---|---|
| 「NEOTOKYOPUNKS」名称 | 中 | ファンメイド明示、商標調査 |
| NTP公式ロゴの使用 | 高 | **使わない**（オリジナルロゴ作成） |
| NFT画像の運営側転載 | 高 | **しない**（ユーザー本人のNFTのみ表示） |
| 世界観・Brainverse名 | 中 | 言及程度に留める、固有名詞は控えめに |
| ギルド名（FUTURE等） | 中 | ファンメイド・自称使用、公式コラボ後に正式化 |
| CPUキャラクター（NEON等） | 低 | オリジナル作成、NTPアートを参考にしない |

### 対策
1. **NTP公式チームへの打診**（Phase 1完成後 〜 Phase 1.5開始時に、動くデモを持って実施）
2. **「Fan-made / Non-official」を常時明示**（フッター、利用規約）
3. **公式素材の直接転載なし**
4. **CPUキャラクター・グラフィックは完全オリジナル**
5. NTPライセンス規約（CC0かそれに準じるか）の確認
6. 公式コラボに発展した場合は別途素材ライセンス契約

### NTPライセンス調査（要実施）
- NTPはCC0を採用しているか、独自ライセンスか
- 商用利用条件（FUTUREギルド所有 = ファンメイド扱いの境界線）
- 二次創作の許諾範囲
- → 公式Discordおよびteam提供ドキュメントを確認

## 11.7 L-06: 景品表示法リスク

### 主な論点
- 「儲かる」「必ず得する」等の誤認誘導
- ガチャ要素を入れる場合の確率表示義務

### 対策
- 広告・LP・X投稿は社内ガイドラインで表現審査
- ガチャ要素はPhase1〜2では入れない、Phase3で必要なら確率表記必須
- ホルダー特典の表現も「特典あり」程度に留め、金銭的優遇とは表現しない

## 11.8 L-07: 個人情報保護法

### 取得する個人データ
- ウォレットアドレス（個人識別性は曖昧、判例待ち）
- ハンドルネーム（ユーザー任意）
- IPアドレス（アクセスログ）

### 対策
- **最小限の収集**: メアド・電話番号・住所等は取得しない
- **プライバシーポリシー策定**: Phase1リリース前に
- **利用目的明示**: アクセスログ・不正検知・統計
- **保存期間制限**: ハンド履歴は365日、ログは90日
- **ユーザー請求対応**: 削除・開示請求への窓口設置

## 11.9 L-08: 海外規制リスク

### 米SEC
- $FGTが「Security」と判定されるリスク（Howey test）
- → 米国ユーザーへの提供を地理的に制限する選択肢

### EU MiCA
- 2024年施行、ユーティリティトークンも一定の規制対象
- EU向け本格展開時に再検討

### 対策
- Phase 3初期は**日本市場優先**、ジオブロックで他地域制限
- ハイリスク地域（米/EU/中国）からのアクセスは利用規約で禁止 + 技術的にも制限検討

## 11.11 緊急対応フロー

法的問題が発生した場合:
1. **即座にサービス停止**を検討（管理画面からKill Switch）
2. 弁護士へ緊急連絡
3. 関連データの保全
4. 影響を受けるユーザーへの告知
5. 当局照会への対応準備
6. プレス対応の準備

## 11.12 弁護士選定の目安

- 暗号資産・ブロックチェーン分野の経験あり
- NFT・GameFi案件の経験あり
- 個人事業主・スタートアップフレンドリーな料金体系
- 候補: アンダーソン・毛利・友常、TMI、Inception Legal、CryptoLaw日本 など

→ Phase 0 期間中に1〜2社へ初回相談（無料相談を活用）
