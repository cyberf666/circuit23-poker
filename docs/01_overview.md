# 01. プロジェクト全体概要

## 1.1 プロダクトビジョン

> **「Brainverse Sector 23、FUTUREギルドが仕切る深夜のポーカーハウス」**
> **PUNKS、ROARS、UTOPIA住人といった3コレクションのプレイヤーと、Brainverse都市の住人NPCが、深夜だけ同じテーブルで対峙する。**

2050年の仮想世界Brainverseに存在する、都市計画から削除された第23区画。
FUTUREギルドがアクセスコードを握り運営。NTP本体ホルダー（PUNKS）、ROARSホルダー、UTOPIA住人、他ギルドメンバー、ゲスト訪問者といった**実プレイヤー層**と、Brainverse都市に登場する**住民キャラクター(BV住人)NPC**が同じテーブルで対峙する。
NEOTOKYOPUNKSの世界観を「毎日5分触れる遊び場」として実体化する、ファンメイドのテキサスホールデムWEBゲーム。

### CIRCUIT 23の登場人物の二層構造
- **プレイヤー層**: PUNK / ROAR / UTOPIAN / GUEST / [ギルド名] / FUTURE
- **NPC層**: BV住人（Brainverse公式世界に登場する住民達をモチーフにしたオリジナルNPCキャラクター）
  - CPU対戦相手として登場
  - 観衆・ディーラー・ストーリーガイドとしても活躍
  - NTP世界観のトンマナを継承するが、IPはオリジナル（ファンメイド範囲）

## 1.2 解決する課題

### NTPコミュニティ側の課題
- NFTを買った後、保有体験が「Discord参加」と「価格チェック」に偏りがち
- ギルド帰属感を実感できる接点が少ない
- ホルダー限定の「遊び」コンテンツが不足

### 一般WEBポーカー側の課題
- 既存サービスはほぼ海外発、世界観・キャラクター性が薄い
- 日本国内向けに「換金しない、純粋にゲームとして遊ぶ」場が少ない
- NFTとゲーム体験の融合が浅く、画像をアバターに使う程度

### このプロダクトのポジション
**「世界観の強さ × ホルダー特典の納得感 × ゲームとしての完成度」** の3点を同時に満たす。

## 1.3 ターゲットユーザー

CIRCUIT 23 のコンセプトは「坩堝」であり、層を限定しないことが世界観そのもの。
ただしマーケティング優先度で以下に区分する。

### 一次ターゲット（Primary）
- **NTP本体ホルダー = PUNKS（約973名）**
  - 既にコミュニティ・世界観への愛着がある
  - Web3リテラシーが高い、ウォレット接続に抵抗なし
  - ギルド帰属意識あり、ホルダー特典への期待値が高い
- **ROARSホルダー**
  - NTPセカンドコレクション保有者（2023年4月リリース、約11,111枚流通）
  - 設定上「PUNKSのコンパニオン（絶滅した日本オオカミのDNAから生成）」を保有
  - PUNKSと並ぶコアコミュニティ層
- **NEO TOKYO PUNKS UTOPIA ホルダー**
  - 第3コレクション保有者、より深層のNTPファン

### 二次ターゲット（Secondary）
- **NTPコミュニティ全般（NFT未保有層）**
  - NTP NFTは未保有だがDiscord等で世界観に親しんでいる層
  - 二次創作者、ファンアーティスト
  - → ゲーム内では `GUEST` ラベルで参加、CIRCUIT 23 でBV住人NPCと対峙する体験
- **NTPに興味があるNFT愛好家**
  - Brainverse世界観に惹かれて触ってみたい層
  - ウォレット接続なしでも遊べる導線が必要
- **国内ポーカー愛好家**
  - 換金性のない「純ゲーム」を楽しみたい層
  - キャラクター/世界観を求めるカジュアル層

> ※ 「BV住人」はゲーム内NPC（Brainverse公式キャラクター都市の住民）であり、プレイヤー層ではない。詳細は[03_game_spec](03_game_spec.md)のキャラクター設計参照。

### 「入り乱れる」体験を設計する
CIRCUIT 23 の魅力は階層と一般プレイヤーが**同じテーブルで対峙すること**にある:
- メインフロアは誰でも入れる → PUNKSと一般プレイヤーが同卓
- ホルダー限定テーブルもある → 濃いめのファン同士の交流
- FUTURE GUILD HOUSEだけは閉じる → ホスト同士の集会
→ 詳細は [07_holder_benefits](07_holder_benefits.md) 参照

### 想定しないユーザー
- 海外のガチ勢ポーカープレイヤー（GTOソルバー前提のシビアな場ではない）
- 課金して稼ぎたいギャンブラー（賭博罪リスク回避のため、換金性は持たない）

## 1.4 競合・差別化

| サービス | 世界観 | NFT連携 | 日本語 | 換金性 |
|---|---|---|---|---|
| PokerStars | 弱 | なし | △ | あり（海外） |
| WPT Global | 弱 | なし | △ | あり |
| Polker | あり | あり | × | あり（クリプト） |
| 既存LINEポーカー | 弱 | なし | ○ | なし |
| **CIRCUIT 23** | **強** | **核** | **○** | **なし** |

差別化の本丸: **「NFTを持っていることがゲーム体験そのものを変える」設計**
- 通常テーブル: 誰でも参加可能
- ホルダー限定テーブル: NTP NFT保有が条件
- FUTUREギルド専用テーブル: FUTUREギルドメンバーのみ
- 特典: 初期チップ、アバター枠、限定エモート、シーズンランキング上位特典

## 1.5 成功指標 (KPI)

### Phase 1（ローンチ初月）
- **アクティブウォレット数**: 100以上
- **平均セッション時間**: 8分以上
- **デイリーリテンション**: D7 25%以上
- **NTPホルダー流入率**: NTP公式Discordリンクからの流入50名以上

### Phase 2（オンライン対戦開始）
- **同時接続ピーク**: 30人以上（テーブル5卓相当）
- **MAU**: 300人以上
- **ホルダー限定テーブル稼働率**: 1日2セッション以上

### Phase 3（トークン導入後）
- **トークンホルダー数**: 500人以上
- **シーズン参加率**: アクティブの60%以上
- **NTPコミュニティからの公式言及**: 1回以上
