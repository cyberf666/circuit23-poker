# 07. NFTホルダー特典設計

## 7.1 設計原則

1. **「持っていることが体験を変える」** が中核。見た目だけでなくゲームメカニクスに影響させる
2. **過剰な格差は作らない**。ホルダー有利は「初動」と「装飾」に限定し、スキルでひっくり返る範囲に
3. **賭博性は持たせない**。換金できない、現金に交換できないことを設計レベルで担保
4. **FUTUREギルドメンバーは特別扱い**だが、明確な根拠（このゲームの主催ギルド）
5. **「入り乱れる」設計**: CIRCUIT 23 の本質は多様性。メインフロアではPUNKS・BV住人・UTOPIA・他ギルド・ゲストが同じテーブルで対峙する。閉じた特典空間と開かれた共存空間を両方用意する

### 7.2.4 テーブル入場権（CIRCUIT 23のフロア構造）

CIRCUIT 23 は4層構造の「入場権」を持つ。坩堝（メインフロア）から閉じた集会（インナーサークル）まで段階的に設計:

| フロア | テーブル種別 | 入場条件 | 想定される入場者 |
|---|---|---|---|
| **メインフロア** (1F) | 公開キャッシュテーブル | 制限なし | PUNK + ROAR + UTOPIAN + 他ギルド + GUEST = **全員が同卓**、BV住人NPCも混在 |
| **VIPラウンジ** (B1) | ホルダー限定テーブル | PUNKS or ROARS or UTOPIA いずれか1体以上保有 | NTP3コレクションの濃い場 |
| **ギルドフロア** (B2) | ギルド限定テーブル | 該当ギルド所属者のみ | 12ギルド各々の集会所、内紛・連携の場 |
| **インナーサークル** (B3) | **FUTURE GUILD HOUSE** | FUTUREギルドメンバーのみ | 主催の密室、運営ミーティングも兼ねる |

### 入場者ラベル（フレーバー）
プレイヤーには所属ラベルが付き、テーブル上で可視化される（誇示・自慢の要素）。
**個人ラベルは単数形で統一**（コレクション名は別途、命名ルールは [03_game_spec](03_game_spec.md) 参照）:

- **PUNK** - NTP本体（PUNKSコレクション）ホルダー
- **ROAR** - ROARSコレクションホルダー（PUNKSのコンパニオンを連れた者）
- **UTOPIAN** - UTOPIAコレクションホルダー
- **[ギルド名]** - 各ギルド帰属者（例: `[HOPE]` `[WAGMI]` `[DENNOW]`...）
- **GUEST** - ウォレット未接続 or NFT未保有のNTPコミュニティ訪問者
- **FUTURE** ⭐ - FUTUREギルドメンバー（金枠）

複数該当する場合は併記表示可能（例: `PUNK + ROAR + [FUTURE]` のような誇示）。

「メインフロアで PUNK + ROAR + GUEST + UTOPIAN + FUTURE が同卓」のような実プレイヤー間の対戦シーンが、CIRCUIT 23 のシグネチャー体験。

### NPCの存在（BV住人）
プレイヤーラベルとは別に、**Brainverse都市住民NPC（BV住人）** がゲーム内に登場:
- CPU対戦相手として座っている（[03_game_spec](03_game_spec.md)のCPUキャラクター3名: NEON / GLITCH / ORACLE）
- 観衆としてテーブル横にいる
- バーテンダーやディーラーとして登場
- これによって「BV住人 + 多様な実プレイヤー層 + FUTURE運営」が同じ空間にいる坩堝が完成する

### コンパニオンとしてのROARS（特別演出）
ROARSは設定上「PUNKSのコンパニオン」。
これをゲーム演出に反映:
- **PUNKS + ROARS 併保有プレイヤー**: テーブルの自席横にROARSアバターを連れて表示できる
- 重要なハンドでROARSが「咆哮」する演出（カードオープン時のSE/エフェクト）
- All-in時にROARSが牙を剥くアニメーション
- ROARS単体ホルダーも自席横に表示可
- Phase 1ではアイコン表示のみ、Phase 2でアニメーション本実装

## 7.3 経済バランス（ソロモード）

NTPホルダー優遇しすぎると一般プレイヤーが続かないため、以下を遵守:
- ホルダー初期チップ最大4,000 = ゲスト1,000の **4倍まで**
- スキル差で1ハンド最大ポット 〜2,000程度 → 数ハンドで逆転可能
- ホルダーがチップ尽きてもリセット可（不利な初期スタックでもやり直しできる）

オンラインでは:
- ホルダー限定テーブル以外は **全員同じBuy-in必須**
- 初期チップは「持ち込み」ではなく「アカウント残高」で、テーブルではフラットにバイインする
- → ホルダー優遇はチップ残高の積み立てやすさに留まり、対戦時の有利不利を作らない

12ギルド全てに同等の「ギルドアイデンティティ」を与えつつ、FUTUREだけは「主催」として一段上の扱い:

| ギルド | 特典 |
|---|---|
| **FUTURE** ⭐ | 主催ギルド: 専用テーブル、限定エモート3種、シーズン報酬2倍、運営権限相談 |
| NEO TOKYO PUNKS | テーブルバッジ表示、専用カードバック |
| HOPE | 専用カードバック、HOPEテーマ着せ替え |
| WAGMI | 専用カードバック、WAGMIテーマ |
| DENNOW | 専用カードバック |
| SKULL | 専用カードバック |
| (他6ギルド) | 各々の専用カードバック・バッジ |

### 「主催ギルド」の正当化
- ファンメイドのスタート時点で「FUTUREギルド所有」を明示し透明性確保
- 他ギルドに不利益はない（プレイ・チップ取得・勝敗に影響しない）
- 公式コラボ後は「主催」ロールが変わる可能性あり → その時に再設計

## 7.5 ホルダー判定の運用

### 判定タイミング
- ログイン時（SIWE認証後にAlchemy照会）
- 24時間経過時の次のアクション時
- ユーザー手動「Refresh」（10分に1回まで）

### 「保有→売却」の扱い
- 売却した瞬間に特典剥奪ではなく、**ホルダーステータスの有効期限は最後の照会から24時間**
- 不正な特典維持を防ぐため、Alchemy Webhookでの転送検知（Phase2以降）を導入予定
- 一度受け取った装飾アイテム（限定エモート等）は**保持**（ホルダー時代の証）

### 「複数ウォレットで同一NFT」対策
- 1NFT = 1人として、最後にログインしたウォレットが優先
- 24時間以内に別ウォレットで同じNFTがログインしたら、古いウォレットのホルダー特典を一時停止
- Phase2で本格対応（NFTのcurrent owner照会で）
